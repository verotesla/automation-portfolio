# Workflow Export

`project-01-customer-inquiry-automation.json` is a sanitized public n8n workflow template.

Before importing it, configure your own:

- Google Sheets OAuth2 credential
- Gmail OAuth2 credential
- Google Sheets document
- Sheet/tab
- Business notification email

The public export intentionally excludes credential references, live Google resource IDs, personal email addresses, and instance-specific metadata.

The workflow is intentionally exported as inactive so it does not start polling immediately after import.
